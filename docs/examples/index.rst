Examples
========

Walkthroughs of programs that ship with ARTS.

.. warning::

   The ``examples/`` source tree is **deprecated**: it predates the current
   public API and does not build (``ARTS_BUILD_EXAMPLES`` is forced OFF and
   enabling it is a configure error).  These pages are kept as reading
   references until the examples are modernized; for buildable, running
   usage see ``tests/ocr/`` and ``benchmarks/``.
