# Archived Array-DB example: `graph_search.c`

`graph_search.c` is an example that consumes the archived Array-DB API
(`arts_new_array_db_with_guid` / `arts_get_from_array_db` / `arts_put_in_array_db`,
declared in the now-archived `arts/array_db.h`). It was already commented out in
`examples/cpu/CMakeLists.txt` (not built) and was removed from the live tree by
the 2026-05-30 cleanup; it is archived here next to the Array-DB library it
depends on. Recover from git `4dc9e92` to restore.
